## 这份教程解决什么

学全栈最常见的卡点不是某个知识点不会，是**不知道东西跑哪了**：改了一个地方没生效、接口报错了不知道看哪、请求发出去了不知道下一步是谁的问题。缺的是一条能走通的链路和一套定位问题的方法。

这份教程的做法是做一个很小的应用——任务清单，四个功能。功能本身两小时就能写完，教程花时间的是每一步「怎么确认这一步真的成了」和「不成的时候按什么顺序查」。
